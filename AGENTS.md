# AGENTS.md - Yukita Fit

## Proyecto
Aplicacion movil para administrar gastos, produccion, pedidos, ventas y ganancias de Yukita Fit.

Stack: Expo/React Native con TypeScript; NestJS, Prisma y MongoDB.
Estructura: cliente en `frontend/`, API en `backend/`, especificaciones en `specs/`.

## Reglas
- Lee `docs/constitution.md` y la spec activa antes de tocar codigo.
- No implementes nada que no este en la spec activa. Si falta una decision, pregunta.
- Un requisito funcional (RF) sin test es un RF no implementado.
- No avances con tests en rojo.
- Cada fase SDD requiere aprobacion humana antes de continuar.

## Al terminar una tarea de implementacion
- Ejecuta la suite de tests aplicable y muestra el resultado.
- Marca el checkbox correspondiente en `specs/NNN-*/tasks.md`.
- Reporta tarea, RF cubiertos, resultado de tests y siguiente tarea propuesta. Espera aprobacion.

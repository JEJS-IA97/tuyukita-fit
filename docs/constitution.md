# Constitucion - Yukita Fit

Principios innegociables. Toda spec, plan y tarea debe cumplirlos.
Si un requisito entra en conflicto con esta constitucion, se detiene el trabajo y se pregunta.

1. **Stack movil**: Expo, React Native y TypeScript. La distribucion Android se realizara mediante EAS Build.
2. **Backend**: NestJS, Prisma y MongoDB; se preparara para despliegue en Render.
3. **La spec manda**: ningun comportamiento se implementa sin un requisito aprobado en la spec activa.
4. **Tests como puerta**: cada requisito funcional tendra pruebas automatizadas en verde antes de avanzar.
5. **Separacion de capas**: interfaz, API, dominio y persistencia deben ser separables y testeables.
6. **Configuracion del negocio**: costos, recetas, sabores, empaques y cantidades por paquete no se codifican como valores fijos.
7. **Historial financiero**: ventas y costos conservaran una fotografia de sus valores para que los cambios futuros no alteren reportes historicos.
8. **Usuarios y permisos**: las cuentas iniciales de Jose, Jai y Vivi tienen los mismos permisos de configuracion y operacion. La gestion de niveles adicionales queda fuera del alcance inicial.
9. **Trazabilidad**: los registros financieros incluyen moneda, fecha, responsable y datos necesarios para auditar cambios.
10. **Idioma**: codigo e identificadores en ingles; interfaz y documentacion en espanol.
11. **Experiencia visual**: diseno movil sobrio y accesible, con fondo blanco suave, `#014325` como color principal, `#82BB2C` para estados positivos y `#F9B02D` para alertas o enfasis.
12. **Calidad**: no se avanza con pruebas en rojo ni con tareas fuera de la spec activa.
